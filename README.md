# Is-Home-Advantage-Dying-What-25-Years-of-Premier-League-Data-Say
<img width="795" height="400" alt="image" src="https://github.com/user-attachments/assets/f51005e6-a11e-4c3d-997a-31f04774e99f" />

Home advantage means teams win more, score more and concede less at their own stadium.
Common explanations are crowd support, referee bias toward the home side, no travel and
familiarity with the pitch. We measure how large the effect is, whether it has shrunk since 2000, and
what happened in 2020–21, when COVID-19 forced almost every match to be played without fans.
That season is a natural experiment: if home advantage drops without crowds and returns with them,
the crowd is a major cause.
